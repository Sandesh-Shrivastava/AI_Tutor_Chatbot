# AI Tutor Chatbot — Frontend

This is the frontend application for the AI Tutor Chatbot portal, built with **React**, **Vite**, and **Tailwind CSS**.

## Features
- **Glassmorphism & Brutalist UI**: Carbon black theme with vibrant orange accents and terminal styling.
- **Zustand State Management**: Persists user session across reloads.
- **React Router**: Seamless single-page transitions between Login and Socratic Chat.
- **Framer Motion**: Smooth entry and scanline micro-animations.

## Development Setup

```bash
# Install dependencies
npm install

# Run development server (runs on http://localhost:5173)
npm run dev
```

## Build for Production

```bash
npm run build
```
The compiled assets will be output to the `dist/` directory.
